# Field Atlas: Self-Improving / Self-Referential LLM Agents (Nov 18, 2026)

Start with **`00_overview.md`**. It has the field on one page, a map of the field, and where each of Dan's ideas sits.

| File | What |
|---|---|
| `00_overview.md` | Big picture, consensus, open problems, how our ideas map onto the field |
| `01_roadmap.md` | Roadmap of everything this project explored (Nov 12–18), with commits and decisions |
| `02_surveys.md` | 18 existing survey papers read in full, each a digest of its taxonomy, definitions, key claims, gaps and brief quotes |
| `chapters/01–16` | 16 area chapters. Each has: at a glance, month-by-month timeline, taxonomy, key-paper fact cards, fact-check log |
| `chapters/17–21` | Corners a completeness critic found missing: embodied RSI, multi-agent/social, label-free RL (TTRL/self-reward), self-made tools & multimodal, deployment + human feedback |
| `glossary.md` | Terms, each with a representative paper |
| `index.md` | Detailed LLM-written index for chapters 1–4 (its input was truncated) |
| `index_full.md` | Auto-generated index of all 868 arXiv ids across every chapter and the survey digests |
| `missing_corners.json` | The critic's gap list and seed papers |
| `FIELD_ATLAS.md` | Everything above combined into one file (~240k words) |

**Marks.**
- ✓ = checked in the paper's full text (about 380 papers were downloaded and read).
- ◐ = abstract only (most ICLR 2027 OpenReview submissions).
- † = from memory or unverified. Check before citing.

Every chapter went through an adversarial fact-check pass.
